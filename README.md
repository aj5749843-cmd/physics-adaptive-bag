# حقيبة أنشطة التعلم التكيفي لمقرر الفيزياء

صفحة تفاعلية فيها ١٥ مفهومًا علميًا في أربعة مجالات: الكهرباء والمغناطيسية، والفيزياء النووية، والصوت والموجات، والضوء والبصريات. لكل مفهوم رابط مباشر لتدريب CK-12 التكيفي.

- تتبّع إنجاز الطالب، ويُحفظ على جهازه.
- زر «المفهوم التالي» ينقل الطالب إلى أول مفهوم لم ينجزه.
- تعمل على الجوال والكمبيوتر، وتدعم الوضع الليلي.

الصفحة ملف واحد (`index.html`) لا يحتاج أي تثبيت.

**إعداد:** أ. أريج الجبرتي

> التدريبات مصادر تعليمية مجانية من منصة CK-12 وتفتح على الموقع نفسه.
